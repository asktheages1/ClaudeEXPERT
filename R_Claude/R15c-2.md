## Caveats

- Many community artifacts are recent with few stars (house-style-lint, astrosteveo/plain-english have 0 stars).\[15\]\[16\] They are useful as templates, not proven at scale. Scott Spence's 84%/20% figures come from his own tests: "84% (42/50)" for forced eval, and his follow-up post says that run was "against Haiku 4.5 with synthetic API calls." In his later sandboxed Claude Code evals, "forced-eval and llm-eval achieved perfect activation and perfect accuracy across all 22 test cases."
- Claude Code changes fast. Version-gated behaviours cited here (Stop `additionalContext` v2.1.163, `/doctor prompt-audit` v2.1.283, house-style-lint needing v2.1.287) should be re-checked against your installed version.
- Items marked A (silence counter, glossary checker, `Skill:` line, stale-path script, Read redirect) are designs built from documented primitives and have not been tested here.
- Whether denied folder names stay visible in `ls`/Glob output is an inference; the docs do not state it.
- Official sources conflict on emphasis wording and on whether file length affects adherence. This report sides with the current prompting guide and treats hard enforcement as the deciding layer.
